# ⏱️ МКС: Таймер смены

Прогрессивное веб-приложение (PWA) для отслеживания рабочей смены, перерывов и обедов. Работает офлайн, устанавливается на телефон, сохраняет данные локально.

## Возможности

- ⏱️ Таймер до конца текущего события и всей смены.
- 🍽️ Расписание перерывов и обедов для дневной и ночной смены.
- 📋 График смен на месяцы с горизонтальной шкалой рабочих часов.
- 🪙 Подброс монеты с физикой и статистикой.
- 🌗 Автоматическая тёмная тема для ночной смены.
- 📴 Работа офлайн после первого открытия.
- 💾 Сохранение данных в localStorage.

## Технологии

Чистый HTML/CSS/JS, Service Worker, Web App Manifest, localStorage.
